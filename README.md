# Kumar Shreyash — Portfolio

A single-page portfolio with a cinematic dark-academia art direction, built on
Next.js 16. Every section backdrop is extracted from the supplied design board;
every claim on the page traces to the résumé or to a repository.

## Running it

```bash
npm install
npm run dev        # http://localhost:3000
```

| Script | What it does |
|---|---|
| `npm run dev` | Dev server |
| `npm run build` | Production build |
| `npm start` | Serve the production build |
| `npm test` | Vitest suite |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run lint` | ESLint |

## Editing the content

Nothing personal lives inside a component. To change what the site says, edit:

| File | Holds |
|---|---|
| `src/config/site.ts` | Name, headline, email, GitHub, LinkedIn, résumé path, nav |
| `src/data/projects.ts` | Projects and their case studies |
| `src/data/experience.ts` | Timeline entries |
| `src/data/skills.ts` | The four skill collections |
| `src/data/achievements.ts` | The Highlights entries |
| `src/data/about.ts` | The letter's subsections |

Adding a project is one object in `src/data/projects.ts`. Give it a `caseStudy`
and it gets a page at `/projects/<slug>` automatically. Leave `githubUrl` or
`liveUrl` out entirely and no link renders — never set them to an empty string.

`npm test` enforces this: it fails the build if any dataset gains a placeholder
string, a link to an unverified host, or a `liveUrl` that is not `https`.

## Artwork

All eight backdrops are generated by one script:

```bash
python scripts/extract_assets.py
```

It writes `public/images/portfolio/*.webp`, the blur placeholders in
`src/lib/blur.ts`, and the social card at `public/og.jpg`.

There are two kinds of source:

- **Five full-resolution scenes** in `design-references/sources/`, at 1672×941.
  Used at native size — no upscale, no sharpening. These cover Home, Projects,
  Skills, Contact and the Footer.
- **Three panels** still lifted out of `harry-potter-portfolio-board.png` — the
  letter, the map and the newspaper. Crop geometry was measured from the board,
  not estimated, and two of those crops deliberately exclude franchise marks
  (a Hogwarts crest and a "Daily Prophet" masthead). See the script comments.

Those three are ~550px at source, so they are upscaled and used as painted
mattes under gradient overlays. **Supplying 16:9 artwork for the About letter,
the Experience map and the Achievements clippings would finish the job** —
drop the files into `design-references/sources/`, add three lines to the
`STANDALONE` table in the script, and re-run it.

Either way, everything crisp on screen — type, rules, the timeline route, the
architecture diagrams, the particles — is drawn by the browser on top.

> After replacing an image, clear `.next/cache/images` before rebuilding.
> Next keys its optimised variants on the request URL, so a replaced file at
> the same path keeps serving the old bytes.

## Spells

A round **Spells** button sits in the bottom-right corner. Opening it shows a
stacked list; each entry reports back whether it took hold or fizzled, because
a spell that silently does nothing is indistinguishable from a broken button.

| Spell | Works on | Effect |
|---|---|---|
| Revelio | Home | Uncovers the scroll hidden one layer behind the castle, under the cursor |
| Lumos | Everywhere | A wandlight that follows the cursor, plus a gentle lift across the page |
| Nox | Everywhere | Puts it out; only offered while Lumos is up |
| Accio | Everywhere | Summons the reader straight to the contact section |
| Alohomora | Skills | Opens every collection at once |

## Loading screen

Every visit opens with a four-second portal: parchment, drifting code
keywords, one of three quotes at random, a glow as the spell takes, then a
zoom through into the site. Under `prefers-reduced-motion` it is a 1.2s fade
with no drift, glow or zoom. Any key or click dismisses it.

Three things keep it from being a trap:

- **The whole sequence is CSS**, ending in `visibility: hidden` with
  `animation-fill-mode: forwards`. If the JavaScript never runs, the overlay
  still clears itself.
- **The real page is in the DOM underneath the entire time** and the overlay is
  `aria-hidden`, so screen readers and crawlers never meet a loading screen.
- **The quote is chosen by the pre-paint script** in `src/app/layout.tsx`,
  which sets `data-quote` on `<html>`; CSS shows the matching one. Picking in
  React would either bake one quote into the static HTML at build time or
  cause a hydration mismatch.

The hero's entrance timeline is built paused and plays on the `splash:done`
event, so it is not wasted behind the overlay.

Duration lives in `SPLASH_MS` (`src/components/splash/SplashScreen.tsx`) and
the matching `4s` in the `.splash` rule in `globals.css` — change both.

## The oath

The Experience timeline starts encrypted as ones and zeroes. *I solemnly swear
that I am up to no good* decrypts it; *Mischief managed* seals it again.

The real text is always in the DOM for screen readers and crawlers — only the
visible layer is scrambled, and the server renders plain text, so the content
survives with JavaScript switched off.

**It starts encrypted because that is the effect as specified.** A recruiter
skimming the page visually will see binary until they press the button. To
ship it decrypted and keep the oath as a toy, flip `STARTS_SWORN` at the top of
`src/components/ui/ExperienceOath.tsx`.

To add one: append to `src/data/spells.ts` with the sections it works on, then
handle its id in `src/components/spells/SpellProvider.tsx`. Anywhere outside
`worksOn` it is marked **inert** in the list and fizzles with a message naming
the section — which is the whole point of the gate, since different sections
are meant to answer to different spells.

`scripts/spell-check.mjs` drives the whole flow in a headless browser and
captures each state.

## Screenshots

`scripts/shoot.mjs` drives the locally installed Chrome through puppeteer-core
and checks for horizontal overflow at each size.

```bash
bash scripts/preview.sh                              # build, serve, all viewports
bash scripts/preview.sh --skip-build --w 1440 --h 900 --to "#projects"
bash scripts/preview.sh --skip-build --reduced       # emulate reduced motion
```

Set `CHROME_PATH` if Chrome is somewhere non-standard.

## Still needs your input

1. **Production domain.** No canonical URL or `metadataBase` is set, because
   inventing one breaks social cards. Fill in `src/config/site.ts` and
   `src/app/layout.tsx` once you have a domain, and add a `sitemap.ts`.
2. **Contact delivery.** The form opens Gmail's web compose in a new tab with
   the message prefilled, and offers a `mailto:` link underneath for anyone
   with a desktop mail client. Nothing is sent by the site itself.
   `src/components/ui/ContactForm.tsx` documents the exact three-step swap to
   Resend if you want real server-side delivery.
3. **Phone number.** On your résumé, deliberately not published. Uncomment the
   field in `src/config/site.ts` to show it.
4. **Repository links** for *LSTM in Pure C++* and *Campus Treasure Hunt*.
   Both are real work, but no public repo URL could be verified, so those two
   cards render without link buttons.
